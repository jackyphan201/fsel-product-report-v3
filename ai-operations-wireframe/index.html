r0.3 · CR-002 · API Keys, Usage & Cost, Prompt

06/11/2026 · USR-05 · PRE-SRS Stage 4 · PROPOSED. WF-SCR-010 quản trị key và liên kết. WF-SCR-011 usage, cost và phân tích. WF-SCR-012 quản trị prompt, lịch sử, context và quyền.

  • Hierarchy dùng chung Tenant → Subject → Feature → Component. Key thuộc Tenant. Attachment chọn đúng provider và key đang hoạt động. Demo dùng bí danh và mã key.
  • Scope mẫu cho Tech / Academic là Tenant A. Admin tổng thấy hai Tenant và chỉnh quyền theo Feature. Academic mặc định bị khóa Config và JSON Schema. Quyền xem payload phụ thuộc ma trận chung.
  • Prompt cụ thể theo MappingId ưu tiên bản hiện hành. Default được dùng khi thiếu bản cụ thể. Các chỉnh sửa được lưu nháp và có lịch sử trước / sau. Kiểm tra JSON ở mức cú pháp và object.
  • Usage & Cost dùng log và đơn giá giả lập. Cache theo provider lấy số token từ log mẫu. Thư viện context dùng trích đoạn và nhận xét ẩn danh cùng vị trí đã duyệt, mặc định tắt. Ví dụ đưa vào prompt có thể làm tăng input.
  • Cần chốt nguồn Tenant / Subject, quyền truy cập sản xuất, vòng đời key và prompt, nguồn đối soát phí và quy trình duyệt dữ liệu dùng lại.
